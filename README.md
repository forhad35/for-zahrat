# 🌸 For Zahrat — 60 Days of Pure Happiness

A dedicated, personalized romantic surprise website handcrafted for Zahrat to celebrate 2 months together.

## ✨ Features Included
- **Surprise Envelope Reveal:** Sealed gift card with gentle wax seal animation. When clicked, it bursts into colorful confetti & floating hearts and unrolls the main surprise.
- **Dreamy Music Box (Web Audio API):** Plays a soft, gentle romantic melody in the background with play/pause and animated equalizer. Zero dependencies, works offline and instantly!
- **Realtime Journey Counter:** Shows live Days, Hours, Minutes, and Seconds counting up every second.
- **Heartfelt Digital Letter:** Beautiful typography with handwritten accent fonts sharing your heartfelt thoughts (*"She is my happiness"*).
- **Interactive Compliment Cards:** 4 interactive cards celebrating her smile, conversations, kindness, and peaceful vibe.
- **"Virtual Hug" Button:** Tap to shower love & confetti, along with sweet randomized affirmations and a hug counter.
- **Floating Petals:** Gentle sakura petals and sparkles drifting softly down the screen.

---

## 🛠️ How to Customize

All text and dates are organized inside `src/data/content.ts`:
- Change the start date: `startDate: "2026-09-21T00:00:00"`
- Change or add new love notes, cards, or sweet whispers!

---

## 🚀 How to Run Locally

```bash
npm install
npm run dev
```

Visit: `http://localhost:5173`

---

## 🌐 How to Deploy for Free (To send the link to Zahrat)

### Option 1: Vercel (Recommended — takes 1 minute)
1. Install Vercel CLI (or push to GitHub):
   ```bash
   npx vercel
   ```
2. Follow the 3 prompts. You will instantly get a link like `zahrat.vercel.app`!

### Option 2: Netlify
1. Run `npm run build`
2. Drag and drop the `dist` folder directly onto [Netlify Drop](https://app.netlify.com/drop)!
